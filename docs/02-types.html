At a glance

Five families. isize/usize are the only platform-dependent widths.

1. Integers

Widths are always explicit; there is no architecture-default integer type.

i88 bits · −128..127
i1616 bits · ±32K
i3232 bits · ±2.1B
i6464 bits · ±9.2E18
u88 bits · 0..255
u1616 bits · 0..65K
u3232 bits · 0..4.3B
u6464 bits · 0..1.8E19
isizeptr size · signed
usizeptr size · unsigned

isize/usize are intended for memory offsets, sizes, and collection indices. They are not interchangeable with fixed-width integers — explicit as required.

Arithmetic, overflow, division by zero

Default arithmetic panics on bad behavior in debug; release wraps. Reach for an explicit family when you want any other rule.
var a: i64 = 1000
var b: i8  = a as i8     // truncates, never panics
var c: f64 = a as f64    // exact for small-enough values
var d: i32 = 3.7 as i32  // truncates toward zero

2. Floating point

f32 and f64, both IEEE 754. Default float literal is f64. No implicit promotion — use as.

Float operations never panic ÷0 → ±∞ · 0/0 → NaN · comparisons with NaN return false. This is straight IEEE 754; if you need a panicking variant, check the value first.

3. Booleans

bool is a primitive type with two values: true and false. It is not a union of singleton structs.

Operations: &&, ||, !, ==, !=. && and || short-circuit. bool has no ordering.

4. Characters

A char is exactly one Unicode scalar value, encoded as a 32-bit value. Surrogate code points are not valid char values. Literals use single quotes; see 01-lexical §7.

var ch = 'A'
var n  = ch as u32          // 65
var c2 = 65u32 as char      // 'A' — panics if value is not a valid Unicode scalar

5. Strings

str is a managed-heap object containing a UTF-8 byte buffer. Immutable: every operation that appears to mutate produces a new str.

A str binding is a heap reference; the buffer is owned and reference-counted.
  • s.byte_size() → UTF-8 byte count (i64).
  • s.size() → Unicode character count (i64); requires a scan.
  • s.get(i) for the i-th character, s.substring(start, end) for slices.
  • + on two str is shorthand for concat.
  • Interpolation lexical rules: 01-lexical §8. ToStr interface: 15-operators.

6. The empty type — null

null is simultaneously the type name and its only value. It is the language's unit type: a function that returns nothing returns null; a discarded expression evaluates to null.

function side_effect(): null {   // explicit
  print("hi")
}

function side_effect() {         // implicit — equivalent
  print("hi")
}

var x: i64 | null = null          // absence via union
No void. No unit. null covers both roles. Use it in unions to express absence: T | null.

8. Default values

No implicit zero The language has no implicit defaults for primitives — every binding must be explicitly initialized. There is no var x: i32; you must write var x: i32 = 0 (or similar). See 06-variables.
