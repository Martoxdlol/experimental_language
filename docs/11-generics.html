1. Type parameters & bounds

function identity<T>(value: T): T { value }
struct Box<T>     { pub value: T }
interface Container<T> { function get(self): T }
extend<T> Box<T>: Container<T> { function get(self): T { self.value } }

function bigger<T: Ord>(a: T, b: T): T { if a > b { a } else { b } }
function dump<T: Printable + Clone>(x: T) { print(x.clone().to_string()) }
function consume<T: Iterator<i64>>(it: T) { ... }

Multiple bounds separate with +. A bound is an interface (possibly with its own generic arguments).

2. Default type parameters

interface Add<Rhs = Self, Output = Self> {
  function add(self, rhs: Rhs): Output
}

// Callers may omit the arguments — Add<> means Add<Self, Self>.

Defaults can refer to earlier parameters and to Self.

3. Bidirectional inference

function pair<A, B>(a: A, b: B): (A, B) { (a, b) }

var p = pair(1, "hi")          // pair<i64, str>
var q = pair<i64, str>(1, "hi") // explicit
var empty = List.new<str>()
No ::<...> turbofish Explicit generic arguments are written in < > immediately after the function or method name. The parser commits to the generic-call interpretation when the name is a known type or generic and < is immediately followed by a type expression. In the rare ambiguous case, parenthesize the comparison: (a < b) > c.

4. Monomorphization — the default

Every distinct set of type arguments produces its own compiled body.

5. Dynamic dispatch — exactly when

The one trigger: an interface name used as a value type — parameter, field, local, return type, generic argument.

Same code shape, very different runtime layout. Pick by whether elements must be heterogeneous.

Widening and narrowing

var person = Person { ... }
var p: Printable = person       // implicit widen — fat pointer
var back = p as Person          // narrow — checks tag, panics on mismatch

Widening produces a fat pointer. Narrowing checks the type tag in the GC header (see 16-memory) and panics on mismatch.

Object safety An interface whose method signature mentions Self outside the self parameter can't be used as a value type — there is no way to express the result in a vtable. The compiler rejects this at use sites; use a generic bound instead. See 10-interfaces §8.

6. Generic structs & interfaces

struct Pair<A, B> {
  pub first:  A,
  pub second: B,
}

struct Cache<K: Eq + Hash, V> {
  inner: Map<K, V>,
}

interface Iterator<T> {
  function next(self): Item<T> | Done
}

interface Add<Rhs = Self, Output = Self> {
  function add(self, rhs: Rhs): Output
}

// Same type, multiple impls with different type arguments
extend i32: Add<i32, i32> { function add(self, rhs: i32): i32 { ... } }
extend i32: Add<f64, f64> { function add(self, rhs: f64): f64 { ... } }

Resolving x.add(y) uses argument types to pick the impl.

7. Overlap & specificity

Two extend blocks can overlap. The compiler picks the most specific applicable impl.

instance of B's pattern, but B's is NOT an instance of A's. Examples extend<T> List<T> extend List<i32> specialization wins (T=i32) extend<T> Wrapper<T> extend<T: Clone> Wrapper<T> bounded wins (narrower) extend<A, B> Pair<A, B> extend<T> Pair<T, T> diagonal wins (A=B) extend<T: Foo> Box<T> extend<T: Bar> Box<T> incomparable → ambiguity error Test is syntactic on pattern shape + bound subsumption — independent of call site. When in doubt: a fully generic blanket impl + a single concrete specialization is the safe pattern.
True ambiguities are rejected; clearly-ordered cases compile.

Bound subsumption

  • If A's bounds are a strict superset of B's, A is more specific.
  • If bound sets are incomparable, the impls are incomparable.

8. Lifetimes & variance

Lifetimes

There are no lifetimes. The GC manages managed memory; FFI pointers are managed through pinning APIs (&, with_pin, Pin.acquire) — see 19-ffi §pinning.

Variance

Generic parameters are invariant. No user-side covariance/contravariance. List<Animal> is not assignable to List<Cat> or vice versa.

Union widening does not propagate through generic containers 
var dog: Dog = ...
var any: Dog | Cat = dog              // OK — bare value widens

var dogs: List<Dog> = ...
var any_list: List<Dog | Cat> = dogs  // ERROR — List is invariant
Build a new collection explicitly: dogs.map({ it as Dog | Cat }).

9. Generics in extern signatures

Generics may appear in extern function declarations only in pointer position (*T), because the size of T is not known at the call site. See 19-ffi.
