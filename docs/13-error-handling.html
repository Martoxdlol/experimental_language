13. Error Handling

No exceptions. No try/catch. Errors are union variants; the postfix ? propagates them; panic handles truly unrecoverable cases.

1. Errors as union variants

struct Error {
  pub message: str,
  pub code: i32,
}

function divide(a: f64, b: f64): f64 | Error {
  if b == 0.0 {
    Error { message: "Division by zero", code: 1 }
  } else {
    a / b
  }
}

var r = divide(10.0, 2.0)
match r {
  f64 v   => print("ok: " + (v as str)),
  Error e => print("err: " + e.message),
}

2. The ? operator

Postfix early-return propagation. The compiler partitions expr's type into success and failure sets based on the enclosing function's return type R:

Partition is by static type assignability to R — failure variants get returned; success variants flow on.
function read_user(id: i64): User | NotFound | DbError { ... }

function summary(id: i64): str | NotFound | DbError {
  var user = read_user(id)?   // ? handles NotFound and DbError; user: User here
  user.name
}
When partitioning fails — three errors
  • Success set empty → "the expression always returns; use a direct match instead".
  • Failure set empty → "nothing to propagate; remove the ?".
  • Some variants neither in R nor strictly successful → "variant X can't propagate; widen R or handle X".

Chained ?

function load_config(): Config | IoError | ParseError { ... }
function validate(c: Config): Config | ValidationError { ... }

function start(): str | IoError | ParseError | ValidationError {
  var c = load_config()?    // strips IoError | ParseError
  var v = validate(c)?      // strips ValidationError
  "ok: " + v.name
}

3. The Try interface — custom propagation

For types that are not unions but want to participate in ? (e.g. a wrapper struct), implement Try:

pub interface Try<Output, Residual> {
  function branch(self): Output | Residual
}

// Usage on v: T where T: Try<O, R>:
v?
// desugars to:
{
  var t = v.branch()
  if t is R { return t }       // possibly with FromResidual conversion
  t as O
}
Built-in for unions The compiler provides a built-in Try impl for unions that performs the partitioning from §2. User code does not implement Try for unions.

4. Residual conversion — FromResidual

When a function returns an error type that is almost what ? would propagate but not exactly, FromResidual lets the compiler insert a conversion.

Direct propagation > FromResidual > compile error.
pub interface FromResidual<R> {
  function from_residual(r: R): Self
}

5. No exceptions, no unwinding

What's missing — on purpose
  • No exception types or throw.
  • No try/catch/finally.
  • No stack-unwinding errors that bubble through frames silently.
Every error is either returned as a value (? or matched) or triggered as a panic (kills the thread). You can grep for ? to see every site that may return early.

6. Panics are not catchable

panic(...) and panic-on-failure operations (as mismatch, integer ÷ by zero, etc.) terminate the current thread. They are not catchable. Use them only for programming bugs and truly unrecoverable conditions; use T | Error + ? for expected error paths. See 14-panics.

7. Style guidance

Style recommendations
  • Define a single error type per module boundary (e.g. AppError) and convert specific errors into it with FromResidual.
  • Use ? for "if this fails I want to return now" and match for "I want to decide based on which failure".
  • Don't use union types with more than ~5 error variants in a public API; collapse them with FromResidual.

8. Examples

struct IoError    { pub kind: str }
struct ParseError { pub at:   i64 }

function read_file(path: str): str | IoError { ... }
function parse(s: str): Config | ParseError { ... }

// Propagating both
function load(path: str): Config | IoError | ParseError {
  var s = read_file(path)?       // strips IoError on failure
  parse(s)?                      // strips ParseError on failure
}

// Wrapping into a single error type
struct AppError { pub message: str }

extend AppError: FromResidual<IoError> {
  function from_residual(e: IoError): AppError {
    AppError { message: "io: " + e.kind }
  }
}
extend AppError: FromResidual<ParseError> {
  function from_residual(e: ParseError): AppError {
    AppError { message: "parse at " + (e.at as str) }
  }
}

function load_wrapped(path: str): Config | AppError {
  var s = read_file(path)?       // IoError → AppError via FromResidual
  parse(s)?                      // ParseError → AppError via FromResidual
}
