We are designing a programming language called **Otter Fusion**. Source files use the `.otter` extension. Inspired in rust.

Most internal identifiers (the `lang` CLI binary, the `lang-lsp` server, `lang_*` runtime symbols, the `LANG_GC` env var, the `source.lang` TextMate scope) are intentionally kept agnostic to the brand name — only user-visible surfaces (file extension, README, docs landing page, VS Code displayName/aliases, restart command title, and the VS Code language id `otter-fusion`) carry the "Otter Fusion" name.

When you write docs, do it in HTML format following existing styles. Add as many diagrams, colors and visual support as you can. Make it as visually appealing as possible. Use CSS for styling and make sure to include it in the HTML document.
